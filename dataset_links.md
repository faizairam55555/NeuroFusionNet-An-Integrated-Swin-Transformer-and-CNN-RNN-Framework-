## Original BraTS access

BraTS 2023 Adult Glioma is associated with the RSNA-ASNR-MICCAI BraTS challenge. The BraTS 2023 Adult Glioma documentation indicates that the dataset is distributed through the official BraTS/Synapse infrastructure and may require registration/access approval.

Official BraTS/Synapse information:
https://www.synapse.org/Synapse:syn51156910/wiki/622351

## Reproducibility

To reproduce the experiments:

1. Obtain the BraTS 2023 Adult Glioma data from an authorized source.
2. Download the dataset according to the source's terms.
3. Place the data in a local directory.
4. Update the dataset path in the relevant notebook.
5. Run the segmentation, classification or baseline-comparison notebook.
